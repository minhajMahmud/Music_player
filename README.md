# TuneFlow Music

Flutter music streaming app with a **Serverpod** backend.

## Backend (Serverpod)

Backend code lives at:

`flutter_app/backend/backend_server`

Quick start:

```
cd flutter_app/backend/backend_server
docker compose up --build --detach
dart bin/main.dart
```

## Flutter App

Run the Flutter app from `flutter_app/` with `flutter run`.
